# Traefik reverse proxy

Traefik v3 terminates HTTPS for the CKA lab platform and gives the browser a
**secure context** (`https://10.8.0.15`), which the Keyboard Lock API requires.

```
browser ──HTTPS:443──> Traefik ──HTTP──> FastAPI/uvicorn 127.0.0.1:3000
                 │
                 ├── /dashboard  → Traefik dashboard (basic auth)
                 └── /metrics    → Prometheus metrics (basic auth)
```

## What it does

| Path            | Target              | Auth              |
| --------------- | ------------------- | ----------------- |
| `/` and SPA     | app `:3000`         | none              |
| `/admin`        | app `:3000` (SPA)   | app's own auth    |
| `/api/*` (app)  | app `:3000`         | app's own auth    |
| `/ws/*`, `/novnc/*` | app `:3000` (WebSocket) | app |
| `/dashboard`    | Traefik dashboard   | HTTP basic        |
| `/api/*` (other)| Traefik internal API| HTTP basic        |
| `/metrics`      | Prometheus          | HTTP basic        |

- `:80` permanently redirects to `:443`.
- TLS uses a self-signed cert with `SAN IP:10.8.0.15` generated by `setup.sh`.
- Access logs, INFO logs and Prometheus metrics are enabled.

The FastAPI app serves its whole backend under `/api/*` (see `web/server.py`),
and the Traefik dashboard also fetches its data from `/api/...`. A blanket
`/api` router would shadow the app and break the SPA, so only Traefik's own
internal API prefixes (`overview`, `version`, `entrypoints`, `http`, `tcp`,
`udp`, `rawdata`, `health` — none of which collide with the app) are sent to the
internal API by the `dashboard-api` router. Every other `/api/*` path keeps
proxying to the app, so e.g. `/api/does-not-exist` returns the app's 404.

## Files

| File                 | Purpose                                             |
| -------------------- | --------------------------------------------------- |
| `traefik.yml`        | static config (entrypoints, provider, api, metrics) |
| `dynamic.yml`        | routers, services, middlewares, TLS                 |
| `docker-compose.yml` | container definition (host network)                 |
| `setup.sh`           | generate cert/users, start the stack                |
| `certs/`             | generated `server.crt` + `server.key` (gitignored)  |
| `users.txt`          | basic-auth credentials (gitignored)                 |

## Deploy / refresh

```bash
cd docker/traefik
DASH_PASS='pick-a-strong-password' ./setup.sh   # or just ./setup.sh
```

Running `./setup.sh` without `DASH_PASS` generates a random password and prints
it **once**. If `users.txt` already exists it is left untouched.

`docker compose` (v2 plugin) is used when present; otherwise an equivalent
`docker run --network host ...` is used automatically:

```bash
docker run -d --name traefik --restart unless-stopped --network host \
  -v "$PWD/traefik.yml:/etc/traefik/traefik.yml:ro" \
  -v "$PWD/dynamic.yml:/etc/traefik/dynamic.yml:ro" \
  -v "$PWD/certs:/etc/traefik/certs:ro" \
  -v "$PWD/users.txt:/etc/traefik/users.txt:ro" \
  traefik:v3.1
```

## Dashboard

- URL: `https://10.8.0.15/dashboard/`
- Username: `admin`
- Password: the value printed by `setup.sh` (or `DASH_PASS`).

### Change the password

```bash
cd docker/traefik
DASH_PASS='new-password' DASH_USER=admin ./setup.sh   # recreates users.txt only if missing
```

`setup.sh` skips `users.txt` when it exists. To rotate, remove it first:

```bash
rm docker/traefik/users.txt
DASH_PASS='new-password' ./setup.sh
```

Traefik's file provider watches `dynamic.yml`; the `users.txt` file is read
per-request, so no restart is needed after editing it in place.

## Use a real certificate later

Replace the generated files and restart:

```bash
cp /path/to/fullchain.pem docker/traefik/certs/server.crt
cp /path/to/privkey.pem   docker/traefik/certs/server.key
docker compose -f docker/traefik/docker-compose.yml up -d --force-recreate
```

Keep the same paths, or point `tls.certificates` in `dynamic.yml` at new files.

## Verify

```bash
curl -sk -o /dev/null -w 'root:%{http_code}\n' https://127.0.0.1/
curl -sk -o /dev/null -w 'admin:%{http_code}\n' https://127.0.0.1/admin
curl -sk -o /dev/null -w 'dash_noauth:%{http_code}\n' https://127.0.0.1/dashboard/
curl -sk -u admin:"$DASH_PASS" -o /dev/null -w 'dash_auth:%{http_code}\n' https://127.0.0.1/dashboard/
curl -s -o /dev/null -w 'http_redirect:%{http_code}\n' http://127.0.0.1/
curl -sk -o /dev/null -w 'api:%{http_code}\n' https://127.0.0.1/api/does-not-exist
```

## Rollback

```bash
docker compose -f docker/traefik/docker-compose.yml down
# or, if started with docker run:
docker rm -f traefik
```

This only removes the proxy; `k8s-web.service` and the desktop containers are
untouched. Ports `:80`/`:443` are freed immediately.
